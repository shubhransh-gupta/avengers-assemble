Installation Guide

Run Scavengers on Your Machine in 60 Seconds

Clone the repository and launch your autonomous superhero coding floor.

# 1. Clone the repository
git clone https://github.com/shubhransh-gupta/scavengers-assemble.git
cd scavengers-assemble

# 2. Install dependencies & compile TypeScript
npm install && npm run build

# 3. Launch the Standalone Multiverse War Room
node bin/stark.js hud --port 3000
⚡ Arc Reactor Core online at http://localhost:3000/warroom.html
